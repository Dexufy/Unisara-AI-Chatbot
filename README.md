# Unisara AI Chatbot

Unisara AI Chatbot is an AI-powered university assistant designed to help students access information quickly and efficiently through conversational interactions. The project focuses on improving communication, accessibility, and user experience within a university environment using modern AI technologies.

## Overview

This project explores the implementation of conversational artificial intelligence for educational support systems. The chatbot is developed to assist students with university-related inquiries while demonstrating the practical integration of AI technologies into real-world applications.

## Features

- AI-powered chatbot interaction
- Real-time response system
- User-friendly interface
- Scalable application structure
- Educational support functionality
- Responsive application design

## Technologies Used

- Flutter
- Dart
- Firebase
- Artificial Intelligence
- Natural Language Processing

## Objectives

- Improve accessibility to university information
- Enhance student engagement through AI interaction
- Develop a practical AI-based support system
- Explore modern chatbot development technologies

## Installation

Clone the repository:

```bash
git clone https://github.com/Dexufy/Unisara-AI-Chatbot.git
```

Navigate into the project directory:

```bash
cd Unisara-AI-Chatbot
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
